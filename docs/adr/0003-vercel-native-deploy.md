# Deploy via integração nativa da Vercel com o GitHub, não um passo de deploy na CI

A integração da Vercel com o GitHub já faz deploy de preview em PRs e de produção a cada push na `main`, sem precisar de nenhum workflow customizado. Deliberadamente não adicionamos um passo de deploy no GitHub Actions pra isso: fazer isso junto com a integração nativa da Vercel ou duplicaria o deploy ou exigiria desabilitar a integração nativa pra centralizar tudo no Actions, e não existe nenhum requisito (passo pré-deploy que a Vercel não consiga rodar, deploy multi-target, etc.) que justifique essa complexidade extra. O GitHub Actions fica restrito a lint + typecheck + Vitest como gate de PR; o deploy é responsabilidade da Vercel.
